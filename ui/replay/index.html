DistAlgo Live

        
      

    

    

      
Add a process, write its DistAlgo code, then write main() to create and start processes.

      
 

    

    

      

        
Pause when

        
      

      

      
A DistAlgo expression over the whole system, e.g.
        some(a in acceptors, has= len(a.received) > 5).
        You can use the variables of main(), procs, network, step and each process class.
        Processes appear as objects with their fields plus id, status, clock,
        received, sent and inbox; the program's own helper functions work too.
